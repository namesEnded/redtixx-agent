# Установка REDTIXX Agent

## 1. Возьмите адрес MCP

Откройте подключение MCP в кабинете Redtixx и скопируйте адрес сервера.

- Организатор: адрес заканчивается на `/mcp/organizer/`.
- Администратор платформы: на `/mcp/admin/`.

Постоянный домен пока не закреплён. Используйте адрес своего кабинета — установщик не содержит адреса демонстрационного сервера.

## 2. Установите плагин

Нужны Node.js 20+, Git и Codex CLI, в котором работает `codex plugin add --help`.

```bash
git clone https://github.com/namesEnded/redtixx-agent.git
cd redtixx-agent
node plugins/redtixx/scripts/setup.mjs --url "ВАШ_MCP_АДРЕС"
```

Замените `ВАШ_MCP_АДРЕС` полным HTTPS-адресом из кабинета. Установщик создаёт локальный каталог в `~/.codex/redtixx-agent` и устанавливает `redtixx@redtixx-agent`. В нём будет только выбранное MCP-подключение. Остальные настройки Codex сохраняются.

Команда `--prepare-only` создаёт каталог без установки в Codex. Параметр `--destination` позволяет указать другую абсолютную папку.

## 3. Подтвердите доступ

Откройте новый чат Codex и выберите REDTIXX Agent. Пройдите OAuth в браузере: собственный вход Redtixx, код аутентификатора и разрешения.

Попросите агента вызвать `get_context`. Он должен показать вашу роль, область доступа и разрешение записи. Организатор выбирает одну свою организацию; администратор подтверждает доступ ко всем текущим и будущим организациям.

Пароли, коды и токены вводятся только в соответствующем интерфейсе авторизации.

## Обновление или смена адреса

В папке репозитория выполните:

```bash
git pull --ff-only
node plugins/redtixx/scripts/setup.mjs --url "ВАШ_MCP_АДРЕС"
```

При смене адреса или отозванном доступе пройдите OAuth заново. После обновления начните новый чат; если приложение не обновило список плагинов, перезапустите его.

## Превью обложек

Для обычной работы эта зависимость не нужна. При первом создании обложки агент устанавливает Playwright в `tools/preview` установленного плагина и браузер Chromium:

```bash
npm ci --prefix "ПАПКА_ПЛАГИНА/tools/preview"
node "ПАПКА_ПЛАГИНА/tools/preview/node_modules/playwright/cli.js" install chromium
```

Рендерер использует компоненты Redtixx. Коммерческий Druk не входит в публичный пакет: получите лицензированный `DrukCyr-Bold.woff2` у своей команды и укажите его папку через `REDTIXX_FONT_DIR`. Открытый Inter Tight включён с лицензией OFL. Генерацию изображений предоставляет ваш AI-клиент. Обложки и превью остаются локальными до выбора и загрузки через MCP.

## Инструкция устанавливающему агенту

1. Получи MCP-адрес у пользователя. Проверь окружение и существующую установку.
2. Скачай этот репозиторий, прочитай установщик и выполни команду из шага 2. Сохрани остальные интеграции.
3. При ошибке остановись и покажи её. Не выдавай подготовленные файлы за установленный плагин.
4. Помоги пройти браузерный OAuth; не запрашивай секреты в чате.
5. Проверь подключение через `get_context` в новом чате. Пока вызов не выполнен успешно, не сообщай, что доступ к Redtixx проверен.

## Удаление

```bash
codex plugin remove redtixx@redtixx-agent
codex plugin marketplace remove redtixx-agent
```

При необходимости отдельно отзовите MCP-доступ в Redtixx. Удаление локального плагина само по себе не отзывает выданное разрешение.

Формат плагина и локального каталога: [OpenAI Docs](https://developers.openai.com/plugins/build/plugins).
